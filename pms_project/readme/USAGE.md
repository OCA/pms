## Assigning a Property to a Task

1. Open a task in **Project ‣ [Project Name]**.
2. Set the **Property** field.
3. Save.

## Viewing Tasks from a Property

1. Open a property in **Properties ‣ Properties**.
2. Open the **Tasks** tab.

The tab lists the tasks linked to the property together with the project
they belong to. Use **Add a line** to link existing tasks; tasks are created
in the **Project** app, where they must belong to a project.

## Searching Tasks and Projects by Property

Open a task or project list, click the search bar and select the property
field (**PMS Properties** for tasks, **Property** for projects).
