This module publishes PMS properties on the website.

It adds website publishing on properties, website categories, property
page templates, and amenity flags for the public site.

**Table of contents**

.. contents::
   :local:

Configuration
=============

- Install **Website** and **PMS Base**.
- Open **Properties ‣ Configuration ‣ Website Categories** to manage
  public categories.
- Open a property form and use the website publish button to make it
  visible on the site.

Usage
=====

Publish a property
------------------

1. Open **Properties ‣ Properties**.
2. Open a property and click **Go to Website** or publish it from the
   form.
3. Visitors can browse the property page at ``/property/<property>``.

Manage website categories
-------------------------

1. Open **Properties ‣ Configuration ‣ Website Categories**.
2. Create categories and assign them on property forms.
