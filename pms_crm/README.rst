This module links the CRM pipeline to the Property Management System.

It includes:

- **Lead/Opportunity counter on properties**: see how many leads
  reference a property directly from the property form.
- **Property counter on leads**: see how many properties are linked to a
  lead or opportunity.
- **Smart buttons**: one-click navigation between properties and CRM
  leads.
- **Bidirectional linking**: a many-to-many relationship allows a lead
  to reference multiple properties and a property to appear in multiple
  leads.

Usage
=====

Linking a Lead to a Property
----------------------------

1. Open a lead or opportunity in **CRM ‣ Sales ‣ Leads**.
2. In the **Properties** tab, add one or more properties.
3. Save — the property's smart button updates its lead count.

Viewing Leads from a Property
-----------------------------

1. Open a property in **Properties ‣ Properties**.
2. Click the **Leads** smart button.
