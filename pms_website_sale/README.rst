This module adds online property booking to the website shop.

Visitors can search published properties, check availability, and add
reservations to the eCommerce cart before checkout.

**Table of contents**

.. contents::
   :local:

Configuration
=============

- Install **Website**, **eCommerce**, **PMS Website**, and **PMS Sale**.
- Publish properties on the website and define reservation types with
  prices.
- The **Properties** menu is added automatically on the website.

Usage
=====

Book a property online
----------------------

1. Open the website **Properties** menu.
2. Search by city, guest count, or date range.
3. Open a property page, choose dates and a reservation type.
4. Add guests and click **Add to cart**.
5. Complete checkout from the cart.

Guests must be logged in to add a booking to the cart.
